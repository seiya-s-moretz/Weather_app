# 天気アプリ 要件定義書

## 1. 概要
**システム名:** 天気確認アプリ  
**概要:** 都市名を入力して現在の天気情報を取得・表示するシンプルな天気アプリ  
**対象プラットフォーム:** Android (Kotlin / Jetpack Compose)  
**使用API:** OpenWeatherMap API（無料プラン）

---

## 2. 目的
- Retrofit を使ったHTTP通信の実装を学ぶ
- JSONレスポンスのパースとデータモデルへのマッピングを学ぶ
- ネットワークエラーのハンドリングを学ぶ
- ローディング状態の管理パターンを習得する
- Repository パターンがDB以外（API）でも有効であることを理解する

---

## 3. 利用者
- 個人ユーザー
- 任意の都市の現在の天気をさっと確認したい人

---

## 4. 機能要件

### 4.1 都市名入力
- テキスト入力欄に都市名（英語）を入力できる
- 「検索」ボタンまたはキーボードの決定ボタンで天気を取得する
- 空文字・空白のみの場合は検索しない

### 4.2 天気情報表示
取得成功時に以下の情報を表示する。

| 表示項目 | 説明 |
|---|---|
| 都市名 | 取得した都市名 |
| 天気アイコン | 晴れ・曇り・雨などのアイコン画像 |
| 天気の説明 | 「晴れ」「曇り」などのテキスト |
| 気温 | 現在気温（℃） |
| 体感温度 | 体感温度（℃） |
| 湿度 | 湿度（%） |
| 風速 | 風速（m/s） |

### 4.3 ローディング表示
- API通信中はローディングインジケーターを表示する
- 通信中は検索ボタンを無効化する

### 4.4 エラー表示
以下のエラーを適切にハンドリングし、ユーザーにメッセージを表示する。

| エラー種別 | 表示メッセージ例 |
|---|---|
| 都市が見つからない（404） | 「都市が見つかりませんでした」 |
| ネットワーク接続エラー | 「ネットワークに接続できません」 |
| タイムアウト | 「通信がタイムアウトしました」 |
| その他サーバーエラー | 「エラーが発生しました」 |

---

## 5. 非機能要件

### 5.1 パフォーマンス
- API レスポンスタイムは通常 1〜2 秒以内を想定する
- タイムアウトは 10 秒とする

### 5.2 信頼性
- ネットワークエラー時はアプリがクラッシュせず、エラーメッセージを表示すること
- 不正なレスポンスが返ってきた場合も適切にハンドリングすること

### 5.3 セキュリティ
- APIキーをソースコードに直書きせず、`local.properties` で管理する

## 6. 画面要件

### 6.1 メイン画面（単一画面構成）

| 要素 | 説明 |
|------|------|
| TopBar | 「天気アプリ」タイトルを表示 |
| 都市名入力欄 | TextField（英語入力） |

## 7. データ要件

### 7.1 APIレスポンス（OpenWeatherMap Current Weather API）

**エンドポイント:**
```
GET https://api.openweathermap.org/data/2.5/weather?q={city}&appid={apiKey}&units=metric&lang=ja
```

**主要パラメータ:**
| パラメータ | 説明 |
|---|---|
| `q` | 都市名（例: Tokyo） |
| `appid` | APIキー |
| `units=metric` | 気温を摂氏で取得 |
| `lang=ja` | 天気の説明を日本語で取得 |

### 7.2 アプリ内データモデル（UI表示用）

```
WeatherUiModel
├─ cityName: String        // 都市名
├─ description: String     // 天気の説明
├─ iconUrl: String         // アイコンURL
├─ temperature: Double     // 気温（℃）
├─ feelsLike: Double       // 体感温度（℃）
├─ humidity: Int           // 湿度（%）
└─ windSpeed: Double       // 風速（m/s）
```

### 7.3 JSON構造
```
{
  "name": "Tokyo",
  "weather": [
    {
      "description": "晴天",
      "icon": "01d"
    }
  ],
  "main": {
    "temp": 25.0,
    "feels_like": 26.0,
    "humidity": 60
  },
  "wind": {
    "speed": 3.5
  }
}
```

## 8. アーキテクチャ要件

```
UI Layer       : Composable（Screen）
ViewModel Layer: ViewModel + StateFlow（UiState管理）
Repository Layer: WeatherRepository（APIを抽象化）
Data Layer     : Retrofit + WeatherApiService（HTTP通信）
```

---

## 9. 制約
- 開発言語: Kotlin
- UIフレームワーク: Jetpack Compose
- 通信ライブラリ: Retrofit + Gson（またはMoshi）
- 画像読み込み: Coil
- アーキテクチャ: MVVM + Repository
- API: OpenWeatherMap（無料プラン・1,000回/日）
